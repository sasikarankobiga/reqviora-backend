# Feature catalog

Everything below describes candidate scope. Priority bands are proposed delivery order for this handoff. Use the [FR matrix](feature-screen-mapping.md) to trace individual requirements.

| Module | Capability | Candidate delivery band | Scope |
| --- | --- | --- | --- |
| M01 | Authentication and project access | Foundation | Accounts, sessions, profile and per-project role grants |
| M02 | Project workspace and draft lifecycle | Foundation | Project management, design profiles and conflict-safe save/resume |
| M03 | Multi-input source hub | First slice / expansion | Text and document inputs first, consented voice after pilot |
| M04 | AI intelligence and clarifications | First slice / expansion | Candidate claims, evidence, human review, questions and quotas |
| M05 | Guided builder | First slice | Manual and AI-assisted authoring, step progress and migration |
| M06 | Feature, screen and traceability management | First slice | Catalogue/defaults, screen selection, mapping and gaps |
| M07 | Navigation graph and journeys | First slice | Route editing, graph presentation, conditions and reachability |
| M08 | Theme, components and interactions | First slice | Tokens, layout, component registry and state contracts |
| M09 | Blueprint and generation | First slice / expansion | Schema-valid compilation and local starters, then controlled AI generation |
| M10 | Visual design editor | First slice / expansion | Property/layout changes, action editing, history and impact checks |
| M11 | Mock preview and design view | First slice / expansion | Simulated journeys and candidate final design view |
| M12 | Validation, review and revisions | First slice / expansion | Deterministic checks first, approval and immutable history afterwards |
| M13 | Second Brain and handoff | First slice / expansion | Draft package first, approved revisions and optional supplement afterwards |
| M14 | MCP, audit and platform operations | Expansion | Revocable read-only context, metering, consent/retention and operations |

Source: BRD §§4, 11 and Appendix B. GUIDE §17.
